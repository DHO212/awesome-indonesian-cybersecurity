## Certification Paths for Indonesian Professionals

### Bug Bounty / Pentesting Path

```
CompTIA Security+ → CEH → OSCP → OSWE/CRTP → OSEP
```

### Security Management Path

```
CompTIA Security+ → SSCP → CISSP → CISM
```

### Cloud Security Path

```
CompTIA Security+ → AWS Security Specialty → CCSP
```

### Web Application Security Path

```
CompTIA Security+ → BSCP → OSWE → GWAPT
```
