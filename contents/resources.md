# Resources

> Indonesian cybersecurity communities, forums, blogs, and media.

## Communities & Forums

### Telegram Groups

- [IDSEC](https://t.me/idsecurity) - Indonesian Security community discussions.
- [IndoBugHunter](https://t.me/indobughunter) - Bug bounty discussion and tips.
- [ID-CERT](https://t.me/idcert) - Indonesian Computer Emergency Response Team updates.
- [IndoSec](https://t.me/indosec) - General Indonesian security chat.
- [KCI - Komunitas Crypto Indonesia](https://t.me/kciid) - Crypto security discussions.
- [ID-CyberWarfare](https://t.me/idcyberwarfare) - Offensive security and CTF discussions.
- [Rumah Siber Indonesia](https://t.me/rumahsiberid) - Cybersecurity awareness and education.

- [IndoSec Discord](https://discord.gg/indosec) - Indonesian cybersecurity community.
