> A curated list of Indonesian cybersecurity resources, tools, communities, events, and more.

Indonesia's cybersecurity ecosystem has grown rapidly, with vibrant communities, skilled bug bounty hunters, competitive CTF teams, and a growing number of local security companies and tools. This list aims to be the single source of truth for anyone interested in Indonesian cybersecurity.

**Contributions welcome!** Read the [contribution guidelines](CONTRIBUTING.md) first.

## How to Use This List

1. **New to Indonesian cybersecurity?** Start with [Communities](contents/resources.md) and [Events](contents/events.md).
2. **Looking for tools?** Check [Indonesian-Made Tools](contents/tools.md).
3. **Interested in bug bounty?** See [Bug Bounty](contents/bug-bounty.md) for local hunters and programs.
4. **CTF enthusiast?** Browse [CTF teams and writeups](contents/ctf.md).
5. **Career-focused?** Review [Certifications](contents/certifications.md) and [Companies](contents/companies.md).
