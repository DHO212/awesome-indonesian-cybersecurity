# Contributing

Thank you for your interest in contributing to the Awesome Indonesian Cybersecurity list!

## How to Contribute

### Adding a New Resource

1. **Fork** this repository
2. **Create** a new branch for your addition
3. **Add** your resource to the appropriate file in `contents/`
4. **Submit** a Pull Request with a clear description

### What Makes a Good Contribution

- **Relevant**: Must be related to Indonesian cybersecurity
- **Active**: Resources should be maintained and current
- **Quality**: High-quality content or tools
- **Accessible**: Available to the Indonesian community
- **Unique**: Not a duplicate of existing entries

### Adding a New Category

1. Create a new Markdown file in `contents/`
2. Follow the existing format and style
3. Add a link to the new file in `README.md`
4. Submit a Pull Request

## Format Guidelines

### For Companies/Teams/Products

```
| Name | Description | Location/Details | Link |
```

### For Tools

```
| Tool | Description | Author/Org | Link |
```

### For Events

```
| Event | Type | Frequency | Link |
```

### For Resources

```
- [Name](URL) - Description.
```

## Quality Standards

- **Links must work**: Verify all URLs before submitting
- **Descriptions accurate**: Ensure descriptions match the resource
- **No spam**: Only genuine, valuable contributions
- **Proper formatting**: Follow the existing table format
- **Spell check**: Proofread your additions

## What NOT to Add

- Personal blogs without security focus
- Commercial products without community value
- Inactive or abandoned projects
- Duplicate entries
- Malicious tools or resources

## Reporting Issues

If you find:
- Broken links
- Incorrect information
- Outdated content
- Spam or inappropriate entries

Please open an Issue with:
- **Type**: Bug, Suggestion, or Report
- **Location**: File and line number (if applicable)
- **Details**: Clear description of the issue

## Pull Request Process

1. **Create** a branch: `git checkout -b add-resource-name`
2. **Make** your changes
3. **Test** all links work
4. **Commit** with a clear message: `Add [resource name] to [category]`
5. **Push** to your fork
6. **Submit** a Pull Request

### PR Description Template

```markdown
## Type of Change
- [ ] New resource
- [ ] Update existing resource
- [ ] Remove resource
- [ ] Fix broken link
- [ ] Other: ___

## Description
Brief description of your change.

## Verification
- [ ] Link works
- [ ] Description is accurate
- [ ] No duplicates
- [ ] Follows format guidelines
```

## Code of Conduct

- Be respectful and constructive
- Focus on quality and accuracy
- Welcome newcomers and help them learn
- No discrimination or harassment
- Credit original authors/creators

## Recognition

Contributors will be recognized in:
- The README contributors section
- GitHub contributors page
- Release notes

## Questions?

If you have questions about contributing:
1. Check existing Issues and PRs
2. Open a new Issue with the "question" label
3. Join our community channels (see [resources.md](contents/resources.md))
